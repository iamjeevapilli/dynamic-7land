Dynamic 7land 1.3 adds **OmniRoute and FreeLLMAPI connections**, Windows setup launchers and an easier **no-API-key local AI setup**.

- **Ollama without an API key:** open Settings → AI connections → Install Ollama + small model. Setup installs Ollama if missing and downloads a small local text model. Choose Use local AI — no key → Load models → Save connection → Test connection. Optional vision-model setup supports screen questions on suitable hardware.
- **FreeLLMAPI:** install its official Windows app using the included checksum-verified setup launcher. Add eligible provider connections in its dashboard, copy its unified connection key, then save and test it in Dynamic 7land. Desktop port defaults to 31415; Docker/server normally uses 3001.
- **OmniRoute:** use Install / start OmniRoute for the pinned npm router and supported Node.js setup. Connect eligible providers in its dashboard, copy an Endpoints key, choose a model or configured free-only combo and test. Default port is 20128.
- Chat, screen questions, Word analysis and reviewed project requests use the selected provider. Gateway connections stay on loopback, refuse redirects and keep keys encrypted separately. Original project path checks, review, backups and undo remain in place.
- The UI explains why the key box clears after saving. **A key is saved** confirms it was retained.

**Routers combine access you configure; they do not make every premium platform free or remove provider quotas.** Configure only eligible free connections and spending controls in your router. Its internal fallbacks and billing are controlled there. For a route requiring no API key or provider account, use downloaded local Ollama models.
