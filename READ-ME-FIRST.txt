DYNAMIC 7LAND 1.4 - ARENA CONNECTION

1. Quit an older Dynamic 7land from its tray menu.
2. Download Dynamic7land-Windows-x64.zip, choose Extract All into a fresh folder and keep every runtime file together.
3. Open Dynamic7land.exe. Windows may hide .exe and show type Application.
4. Right-click the robot near the clock > Settings > AI connections.
5. Paste your Arena key into Arena API key and keep model coding-router-preview, or select a model enabled for your workspace.

FREE-ROUTER KEY: Choose Interactive Claude Code only (free-router). If Claude Code is missing, click Install Claude Code, complete installation and Refresh status. Choose Save and open Claude via Arena. Ask a question in its terminal to verify the connection. Enable Claude Code in Connections for island session monitoring.

API-ENABLED WORKSPACE: Choose Workspace with API access > Save connection > Test connection. A successful test says Connection successful. Arena returned an answer. API usage follows Arena's workspace pricing and quotas.

A free-router key cannot run direct desktop chat, screen questions or project API requests. Changing the access choice does not grant workspace permission.

The key box clears after saving. A key is saved means the encrypted key remains stored for your Windows account. Leave the input blank to keep it. No private key is included in this public release.

Open island: right-click the tray robot > Open island, then click the chat bubble. Dynamic7land-Settings.cmd opens Settings directly. Ctrl+Alt+T also shows the island.

The added alternative providers and their installers have been removed. Claude/Codex monitoring and existing account connections remain. Extract into a fresh folder to avoid mixing old setup launchers with this update. Other Windows apps and models are not uninstalled.

Read AI-SETUP.md for setup and troubleshooting. Credits and license notices remain in the attribution files.
