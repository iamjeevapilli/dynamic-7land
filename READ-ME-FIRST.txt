DYNAMIC 7LAND 1.2 — FREE CLOUD AND LOCAL AI

1. Extract the complete ZIP with Extract All.
2. Open the extracted Dynamic7land folder.
3. Open Dynamic7land.exe. Windows may show the name as Dynamic7land (Application).
4. Open Settings → AI connections.

FREE CLOUD: Choose Use free cloud models. Get a free OpenRouter key using the button, paste it in the app, keep openrouter/free, save and test. Only free model routes are allowed. Quotas and model availability still apply. No credit purchase or Arena approval is needed for this setup.

LOCAL AI: Install Ollama with the official download button and download a local model. Choose Use local AI → Load models, select it, save and test. No API key or AI API fees. Download size, memory use and speed depend on the model. Screenshot questions need a local vision model such as gemma3:4b. Cloud models are blocked in this route.

Your existing Claude, Codex, Arena and Claude API connections are optional and follow those services' account limits. Sign in to ChatGPT for Codex through AI & Chat.

To show the notch, right-click the robot icon near the Windows clock → Open island. Choose Settings from the same menu to reopen configuration. Dynamic7land-Settings.cmd also opens Settings directly. Quit an older instance before starting an updated version.
